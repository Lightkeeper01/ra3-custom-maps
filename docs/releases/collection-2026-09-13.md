# Initial public map collection - 2026-09-13

This release publishes three independent maps for vanilla Red Alert 3 (PC, 1.12), with English installation documentation, downloadable source bundles and SHA-256 checksums.

- **Black Tide v1.0**: the latest compact objective-driven map. English ASCII captions, opening raid squads, rotating 45-second relay contracts, randomized salvage, mixed-faction reinforcements, six-minute reward escalation and first-win coastal artillery. Experimental; full in-game playtesting is still required.
- **Strait Storm v1.2**: the larger archipelago with random supplies across 15 sites and 120-second coastal-gun challenges. Experimental; legacy Chinese event captions can have compatibility issues.
- **Strait Reunification v0.9.2**: the original conventional skirmish map, reported playable by its author.

Public player archives have been repackaged with English README files and portable installation scripts. The four native files in each map are byte-for-byte unchanged from their respective delivered versions. Personal workstation paths and installation-session logs are not included.

Download the player ZIP rather than a source ZIP to play. Install each map in its own folder; all three can coexist. Please submit reproducible bugs and balance feedback through GitHub Issues.
